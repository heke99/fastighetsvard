# Product and Users

FaddeBo serves one legal landlord and its applicants, tenants and operational
partners.

| Actor | Goal / primary journey |
| --- | --- |
| Platform owner/admin | Configure, secure and operate the platform |
| Landlord owner/admin | Govern portfolio, staff and compliance |
| Property/leasing manager | Publish units, review applicants, arrange viewings and offers |
| Finance manager/user | Manage invoices, payments, reconciliation and exports |
| Maintenance manager/agent/caretaker | Triage cases, schedule work and close quality checks |
| Document manager/auditor/security auditor | Control evidence, retention and audit access |
| Applicant/co-applicant/guarantor | Build profile, submit evidence, apply, attend and sign |
| Tenant/co-tenant/former tenant | Use portal, pay, communicate, report faults and move out |
| Supplier/contractor | Access only assigned work |
| External integration | Exchange scoped, idempotent, auditable data |

The legal owner, FaddeBo brand, property manager and property itself are distinct
concepts even when one organization currently fills several roles.
