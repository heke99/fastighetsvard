# Glossary

- Brand: customer-facing FaddeBo identity.
- Legal organization: Östgöta El Teknik AB, the contracting/controller entity.
- Unit: rentable/saleable physical object.
- Listing: published commercial presentation of a unit.
- Application snapshot: immutable submitted applicant facts/rules.
- Reservation: exclusive time-bound unit allocation.
- Contract version: immutable lease content candidate.
- Tenancy: active legal/operational rental relationship, distinct from PDF/version.
- RLS: PostgreSQL row-level security.
- Outbox: transactional record of asynchronous work to deliver.
- Canonical: single authoritative model/path for a capability.
